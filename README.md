# cougarnet
This is the home for courgarNET's documentation and work in progress.
## About us
This repository hosts cougarNET's ongoing project to plan, build and maintain a enterprise level network! Along the way, there will be tons of hardware introduced, services enabled and changes made. All will be documented here! Prospective members must join IEEE-CS to join CougarNET, all experience levels are welcome! 
## Progress so far
Meeting are ***planned*** to be every **Tuesday** and **Thursday** between **4:00 P.M - 5:30 P.M** (time subject to change)\
We are in **Phase I**, objectives include:\
* Researching company requirements 
* Determining necessary devices
* Choosing network topology
* Map out connections and assignments
